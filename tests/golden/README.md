# Golden fixtures

`Golden/*.json` are **generated fixtures** — do not edit by hand. They lock
the exact values of the TA-Lib catalog so any regression in the bundled
managed port (`src/lib/TA-Lib-Core.dll`) or the .NET runtime fails the test
suite instead of silently changing every indicator on screen.

- Generated by: `generate_goldens.py`
- Reference implementation: the canonical C TA-Lib, via the python
  `ta-lib` bindings (independent of the C# port under test)
- Consumed by: `tests/fxpa.tests/CatalogGoldenTests.cs`
- Input series: 512 seeded prices (`seed=42`, random walk from 100.0 with
  uniform(-1.5, 1.6) steps), with deterministic high/low/volume series —
  see `make_inputs()` in the generator.

## Regenerating

Requires python 3 with numpy and ta-lib:

```bash
python3 -m venv .venv
.venv/bin/pip install numpy ta-lib
.venv/bin/python generate_goldens.py
```

Commit the regenerated JSON together with the change that motivated it.

## When a value legitimately changes

A mismatch means the managed port now produces different numbers. If — and
only if — that difference is intended (e.g. adopting a newer TA-Lib port),
regenerate the fixtures, review the diff of actual values, and commit the
new goldens with an explanation in the commit message. Otherwise the test
is telling you the change is a regression.
